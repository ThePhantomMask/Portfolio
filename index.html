Current Projects

Scaryland: Forbidden Park

Scaryland: Forbidden Park is a story-driven adventure horror game set in an abandoned theme park cursed by a mysterious presence.

The gameplay draws inspiration from the Silent Hill, Resident Evil and Siren series. During the music segments, it turns into a rhythm game inspired by Gitaroo Man and Taiko no Tatsujin.

The visual style is an homage to 32/64-bit era games (N64 and PS1), blended with the look of early-'90s children's cartoons and anime, reimagined in a horror setting.

In development

  • Technologies: C#, C++
  • Audio: FMOD
  • Engine: Flax Engine
  • Previously used: Godot, Unity

Flax Engine

Flax Engine is a high-quality, modern 3D game engine written in C++ and C#. Designed for a fast workflow, it comes with many ready-to-use features. Created by Wojciech Figat and contributors.

What I contributed:

  • UI: Added a customizable HighlightedColor property to the Dropdown control, letting developers define the color used to highlight items on hover or selection. Added line-wrapping support to the Rich Text Box. Added keyboard and controller support to the Slider.
  • Core: Added Normalize functions for Vector4 on the C++ side, and Slerp (spherical linear interpolation) functions for vectors in both C# and C++. Added the missing boolean transparency property to Color in C#. Added status values to the Video Player.

Connection Lost

CONNECTION LOST – Connect. Launch. Survive the Flow. What happens when a robot is left behind in a forgotten factory? You get PipeBot, a determined little machine with no legs, a trusty pipe launcher, and one job: restore power and escape. Connection Lost is a high-voltage reimagining of the classic pipe-connection puzzle genre — but in full 3D, with fast-paced physics, precision shooting, and a magnetic twist. Armed with the PipeLauncher5001, you’ll shoot, stick, and connect pipes on magnetic grid walls to channel energy from power sources to endpoints. Solve the puzzles. Master the momentum. And keep the current alive.

What I developed:

  • Implemented a pipe-firing system with object pooling, collision detection against magnetic surfaces, and real-time visual feedback driven by material parameters in UE5.
  • Developed a dynamic pipe-inventory UI with real-time preview.
  • Created an automatic out-of-bounds object removal system, optimizing memory through object pooling.
  • Role: Gameplay Programmer
  • Technologies: C++, Blueprints
  • Engine: Unreal Engine 5
